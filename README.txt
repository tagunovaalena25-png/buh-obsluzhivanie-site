# Бух Обслуживание — сайт на Python (Flask)

## Запуск в Windows 11

1. Распакуйте архив в папку, например `BuhSite`.
2. Откройте папку проекта в Проводнике.
3. Нажмите на адресную строку Проводника, напишите `cmd` и нажмите Enter.
4. В открывшемся чёрном окне выполните команды по очереди:

```bat
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
py app.py
```

5. Откройте браузер и перейдите на http://127.0.0.1:5000

Чтобы остановить сервер, вернитесь в чёрное окно и нажмите `Ctrl+C`.

## Важно перед публикацией

- В `templates/index.html` замените демонстрационные телефон, email, адрес, отзывы, партнёров, цифры и реквизиты на реальные.
- Карта — декоративная заглушка; встроите настоящую карту вашего офиса.
- Форма в демо-режиме выводит данные в окно терминала. Она не отправляет email и не сохраняет заявки в базу данных. Подключите надёжный обработчик перед запуском сайта для клиентов.
- Ссылки на политику и согласие — заготовки, а не юридические документы. Подготовьте корректные документы перед публикацией.
- `debug=True` используется только локально. Для размещения в интернете потребуется production-сервер и настройки безопасности.

## Структура проекта

- `app.py` — Python-сервер и обработчик формы.
- `templates/index.html` — структура страницы.
- `static/style.css` — оформление сайта.
- `requirements.txt` — необходимые библиотеки.
